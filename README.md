# Client Nutrition Management System

A deployed full-stack web application for client nutrition management, personalized meal planning, progress tracking, and nutrition reports.

## ✨ Key Features

- Client nutrition profile management
- Personalized nutrition and meal planning
- Weight and progress tracking
- Role-based access for clients, doctors, and administrators
- PDF nutrition report generation

## 🛠️ Technology Stack

- React and Vite
- Python and FastAPI
- PostgreSQL with Neon
- Vercel and Railway

## 🏗️ Project Overview

This project demonstrates full-stack web development, API integration, database management, and deployment of a production-hosted web application.
